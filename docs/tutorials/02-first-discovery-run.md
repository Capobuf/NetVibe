# Tutorial 02 — Prima discovery run

## Obiettivo
Popolare IPAM a partire da una subnet e gestire eventuali proposte/conflitti.

## Passi
1. Crea una VLAN e una Subnet (IPAM).
2. Associa `customer_id` alla Subnet.
3. Esegui una discovery ICMP on-demand (vedi `docs/how-to/operations/run-discovery-on-demand.md`).
4. Consulta gli IP creati/aggiornati.
5. Se vengono creati Discovery Events: apri Discovery → Discovery Events e gestisci PENDING.
