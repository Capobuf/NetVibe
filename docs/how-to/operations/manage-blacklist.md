# Manage blacklist (VLAN/Subnet)

## Dove
Filament → IPAM → **Blacklist**.

- VLAN Blacklist
- Subnet Blacklist

## Comportamento
Un elemento in blacklist:
- non viene importato dall'ingest MikroTik
- non viene creato/aggiornato durante la discovery

## Shortcut (as-is)
Nella tabella Subnets esiste un'azione per aggiungere/rimuovere la subnet dalla blacklist.
