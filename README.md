# NetVibe

NetVibe è un IPAM IPv4 leggero per MSP che gestiscono più clienti e sedi, utilizzabile anche senza integrazioni.

Il repository è in fase di ripartenza: contiene la documentazione ufficiale, senza codice applicativo, starter kit o dipendenze installate. Lo storico Git è conservato e non costituisce una fonte di implementazione per la nuova versione.
