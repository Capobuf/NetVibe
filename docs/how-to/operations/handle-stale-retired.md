# Handle stale/retired inventory

## Dove
Nelle liste Filament di:
- IP Addresses
- Devices
- Ports

## Cosa fare
- Usa il filtro **Lifecycle** per trovare oggetti **Stale** o **Retired**.
- Se un oggetto è tornato attivo (o vuoi ripristinarlo manualmente), usa la bulk action **Restore (Active)**.

## Policy
Le soglie e l'abilitazione sono in Discovery Settings. Vedi: `docs/reference/operations/soft-retire-policy.md`.
